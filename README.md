# Market Indicator

Seven warning signs before a market bubble pops: an interactive explainer with
seven charts (Shiller CAPE, Excess CAPE Yield, Buffett indicator, yield curve,
rate hikes, narrow leadership, margin debt).

Live at https://market-indicator-pink.vercel.app

The whole site is a single static page, `src/index.html` (Chart.js loads from
cdnjs). Open it in a browser to preview. Vercel serves the `src` folder.
